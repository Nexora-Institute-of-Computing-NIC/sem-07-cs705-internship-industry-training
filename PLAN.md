# CS705 — Internship / Industry Training — PLAN

**Semester:** 7 · **Credits:** 4 · **Level:** Advanced-Professional
**Theory:** 0 hrs · **Internship:** 8–12 weeks · **Tools:** Whatever the host organisation uses

## Course Format
A full-time internship (or equivalent industry training) with an external host organisation — a company, research lab, or open-source project. Minimum 8 weeks full-time (or 12 weeks part-time). The student is mentored by a host supervisor and an academic supervisor.

## Objectives

1. Apply the technical skills from Semesters 1–6 to a real, non-trivial problem.
2. Work inside a real engineering team — code review, standups, planning.
3. Deliver something the host can actually use.
4. Reflect honestly on what is different between academic work and industry.

## Internship Requirements

### Before the Internship
1. **Host secured** — signed internship letter or email confirmation
2. **Internship plan agreed** — one page with host supervisor, duration, project, deliverables
3. **Academic supervisor assigned** — a faculty contact at NIC
4. **Ethics and NDA check** — if the work is confidential, the write-up uses appropriate abstraction

### During the Internship (Weekly)
1. **Weekly update** — 150-word summary of what was done, one blocker, one learning
2. **Code contributions** — whatever the host allows, in the student's own fork or lab repo
3. **Mentor meetings** — at least one 30-minute check-in per week with the host supervisor

### After the Internship
1. **Final report** — 2,000–3,000 words, structured as below
2. **Deliverable walkthrough** — the artefact produced (code, design, analysis)
3. **Exit interview** — 15-minute presentation to the academic supervisor

## Final Report Structure
Host organisation and team context

The problem — what needed solving and why

What I built / analysed / delivered

Technical challenges and how I solved them

What I learned that I could not have learned in class

Honest reflection — what I would do differently

Reference letter or host supervisor confirmation

text

## Weekly Log Structure

Each week's `weekly/week-NN.md`:
- **Done** — what was completed
- **Blocked** — what is stuck and how it was escalated
- **Learned** — one concrete thing learned this week
- **Next** — plan for next week

## Assessment

| Component | Weight |
| :--- | :---: |
| Host supervisor evaluation | 40% |
| Weekly logs and progress | 20% |
| Final report (rigour, honesty, clarity) | 25% |
| Exit presentation | 15% |

## Common Failure Modes to Avoid

- Treating the internship as a summer camp — turn up, deliver, take responsibility.
- Claiming work in the report that was not actually done.
- Hiding blockers until they blow up — escalate early.
- Skipping the weekly logs (they cannot be back-written).

## If an Internship Cannot Be Secured

Substitute an **industry-equivalent training engagement**:
- A 10-week structured open-source contribution project with a mentor
- A paid or unpaid apprenticeship at a local tech firm
- A structured research assistantship with a professor

The report structure and assessment remain the same.
